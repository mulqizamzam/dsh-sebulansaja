# dsh-sebulansaja

A standalone DeepSeek-Native Harness (DSH) bundle for time-bounded, evidence-oriented research across publicly accessible sources.

**Maintainer:** mulqizamzam  
**Target runtime:** DeepSeek-Native Harness (DSH) `0.2.1-rc.2`

## Status

Repository bootstrap only. Runtime compatibility and source-provider integration must be verified against the target DSH installation before treating this project as a complete release.

## Planned workflow

- Query publicly accessible research sources within a user-selected date window.
- Normalize and deduplicate dated results.
- Preserve source URLs and timestamps for follow-up verification.
- Report per-source failures separately from successful results.

## Installation

Installation instructions will be added after the DSH bundle structure and runtime smoke tests are confirmed. Do not assume the npm package is published yet.
